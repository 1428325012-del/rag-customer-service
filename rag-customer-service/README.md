# 网店智能客服（RAG 问答系统）

从零实现的 RAG（检索增强生成）客服问答系统：把 FAQ 切块 → 向量化 → 检索最相关段落 → 大模型基于段落生成回答，并标注来源段落。

> 个人练手项目，重点是把 RAG 全链路跑通：能用、能讲清楚。

## 效果（自建测试集）

| 指标 | 结果 |
|---|---|
| 答对率 | 100%（9/9） |
| 知识库外幻觉率 | 0% |
| 平均检索耗时 | 0.22 s |
| 平均回答耗时 | 3.29 s |

测试集构成：4 个常规问题 + 2 个改述问题（如「退费」→「退款」）+ 3 个知识库外问题。

## RAG 流程

```
【建库 · 一次】
FAQ 文件 → 按句切块（120 字 / 重叠 20 字）→ bge-m3 向量化 → 存入向量库

【提问 · 每次】
问题 → 向量化 → 余弦相似度检索 top-3
     → 拼接「资料 + 问题」→ 豆包生成回答（标注来源）
```

## 两种实现

| 文件 | 说明 |
|---|---|
| `service.py` | 完整版：检索 + 生成 + 工具调用（查物流）+ 多轮对话 + 防幻觉与引用校验，零第三方依赖 |
| `rag_chroma.py` | Chroma 持久化版：用 Chroma 建索引并持久化，演示向量库的存储与检索 |

## 快速开始

1. 安装依赖（仅 Chroma 版需要）：
   ```bash
   pip install -r requirements.txt
   ```
2. 在同目录新建 `.env`：
   ```
   ARK_API_KEY=你的火山方舟密钥
   ARK_CHAT_MODEL=你的聊天模型 endpoint id
   EMBED_BASE_URL=https://api.siliconflow.cn/v1
   EMBED_API_KEY=你的硅基流动密钥
   ARK_EMBED_MODEL=BAAI/bge-m3
   ```
3. 运行：
   ```bash
   python service.py
   ```

## 设计要点

- **切块 + 重叠**：按句子切、块间重叠 20 字，避免把一句话切断；
- **语义检索**：用 bge-m3 生成 1024 维向量，余弦相似度取 top-3；「退费」≈「退款」（相似度 0.93），换个说法也能命中；
- **防幻觉（两层）**：提示词约束（只说资料里有的事）+ 程序校验（答案里的来源段号越界则拦截）；
- **引用**：回答末尾标注「来源：第 X 段」，可追溯；
- **工具调用**：物流查询走 `CALL:query_logistics:<单号>` 协议，先判断再执行；
- **多轮对话**：保留最近 3 轮历史，控制上下文长度。

## 说明

个人练手项目：FAQ 数据量小（十几条），重点验证链路可行性；生产环境需接入更大知识库与向量数据库。
